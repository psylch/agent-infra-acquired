四、收购集中在什么时候

时间 收购 同期大事

2025 Q4 Pipedream、Stytch（11 月）；Bun、Neptune、Manus（12 月） Claude Code 年化收入破 $10 亿（11 月）
2026 Q1 Langfuse（1 月）、Tavily（2 月） Portkey、Daytona 刚融完 A 轮

  • 第一波（2025 下半年）是模型公司和安全公司在买，买团队和底座，配合 coding agent 爆发。
  • 第二波（2026 Q2）最密，买家换成数据库、企业 SaaS 和安全巨头，买的是「agent 进企业」要过的关：接入、权限、观测。
  • 第三波（2026 下半年）是 infra 公司互相合并，推理、沙箱、数据库往一朵「agent 云」里收。
  • 每一波都跟在协议或产品拐点后面：ACP / AP2 之后买安全，MCP 普及后买接入层，个人 agent 起量后买执行层。

五、谁在买，买什么

  • 买家几乎都是老平台：数据库（ClickHouse、Snowflake、Supabase）、安全（Palo Alto、Check Point、Cisco）、企业 SaaS（Workday、Asana）。它们买的是「agent 进来以后，我这层不被绕开」。
  • 模型公司买的是自己用的工具：Anthropic 买 Bun 和 Humanloop，OpenAI 买 Neptune，是补自家研发和 Claude Code 这类产品的底座。
  • 基础设施公司开始互相吞：Modal 买 Butter，Baseten 买 Blaxel，推理和沙箱在合到一朵「agent 云」里。
  • 价格普遍不高：公开的多在 $1–4 亿，单点工具很难自己长成平台，卖给有分发的人是常见结局。
  • 例外是两头：入口端的 Manus 卖到 $20 亿以上，联网端的 Exa、Parallel 独立估值 $20 亿级。

六、价值在两端

  • 入口端：谁握着用户和任务，谁就有议价权。Manus 被买走的是付费用户和产品，不是技术栈。
  • 供给端：谁握着 agent 要用的网页、数据和执行环境，谁就能收过路费。搜索和沙箱是目前最贵的两层。
  • 中间层（网关、观测、连接器、编排）最容易被平台顺手做掉，所以最先被收购。

  • 支付层基本被卡组织、Stripe、Coinbase 这种老玩家用「协议」占住了，创业公司只能做钱包和微支付。
  • 邮箱和身份更像入口方的标配：Grok Bot 直接内置邮箱，独立的 AgentMail 只能卖给开发者。
  • 这一层里被收购的目前只有 Stytch，买家 Twilio 也是通信老平台。
  • 真正的增量在商家侧：Lorikeet 这类客服厂商愿意为个人 agent 开门，才是准入问题的解法。

八、个人 agent 常驻手机之后

  • Grok Bot、Muse、Instinct 这类 always-on agent 自带电脑、浏览器和记忆，开发者拼装的那套中间件，被入口方直接内化。
  • 剩下的硬需求是「能不能进门」：网站拦代购 agent、登录态、支付和身份。瓶颈从模型转到准入。
  • 新机会在供给方这侧：Lorikeet 用 Personal Agent Protocol 让 Instinct 完成银行身份认证，说明商家开始为 agent 开专门的门。
  • Muse 把最强模型放进 $20/$100 月订阅，入口方在找收费方式；入口越贵，越需要便宜可靠的执行层。
  • 国内是同一条线：腾讯 LightVela 从微信接入，字节在推「Spell」。入口被大厂拿着，独立 infra 的机会在给它们供货。
  • 判断：未来值钱的 agent infra，要么是入口方买不到、做不出的数据和准入，要么是大到能被入口方当供应商的执行云。
