  • 第一波（2025 下半年）是模型公司和安全公司在买，买团队和底座，配合 coding agent 爆发。
  • 第二波（2026 Q2）最密，买家是数据库、企业 SaaS 和安全巨头，买的是 agent 进企业要过的关：接入、权限、观测。
  • 第三波（2026 下半年）是 infra 公司互相合并，推理、沙箱、数据库往一朵「agent 云」里收。

五、谁在买，买什么

  • 买家几乎都是老平台：数据库（ClickHouse、Snowflake、Supabase）、安全（Palo Alto、Check Point、Cisco）、企业 SaaS（Workday、Asana）。它们买的是 agent 进来以后自己这层不被绕开。
  • 模型公司买自己要用的工具：Anthropic 买 Humanloop，OpenAI 买 Neptune。
  • infra 公司开始互相吞：Modal 买 Butter，Baseten 买 Blaxel。
  • 公开价格多在 $1–4 亿，单点工具很难自己长成平台；独立做大的只有联网层的 Exa、Parallel（估值 $20 亿级）。

七、投资判断：2026 年 10 月这一刻

这一刻新在哪

  • agent 的用户变了：以前是开发者在自己的系统里跑 agent，现在是 Grok Bot、Muse、Instinct 这类常驻手机的个人 agent，替消费者在别人的系统里办事。
  • 瓶颈跟着挪了：模型和工具已经够用，卡点变成「让不让进」，也就是身份、授权、商家接不接、谁付钱、出事谁负责。VanEck 的 Matthew Sigel 说几乎每个购物网站都在拦 Instinct 和 Muse。
  • 风险开始落到商家那一侧：Musk 晒 Grok Bot 买乐高的截图露出订单号，别人拿去让乐高的 AI 客服改了单。
  • 商家侧的门开始出现：Lorikeet 让 Instinct 走 Personal Agent Protocol 完成银行身份认证并查余额；Blomfield 预警「客服海啸」，Sarah Guo 写《Friction》讲摩擦消失后的后果。

对照收购数据

收购波次 买的是什么 跟这一刻的关系
2025 下半年：模型公司、安全公司 团队、评测、提示注入防护 解决 agent 能不能干活
2026 Q2：数据库、SaaS、安全巨头 接入、权限、观测、网关 解决企业放不放 agent 进自己系统
2026 下半年：infra 互相合并 沙箱、推理、数据库 解决 agent 在哪跑
还没人买 商家侧接收、agent 身份核验、授权与责任、客服侧防欺诈 解决消费者的 agent 进不进得了别人家
  • 已有的收购都在「发起方」这边，帮 agent 出去办事；「接收方」这边，也就是商家怎么认 agent、怎么放行、怎么防骗，还几乎空白。
  • 这一侧唯一像样的交易是 Twilio 买 Stytch，买家是通信平台，正好是要接住「客服海啸」的那类公司。

美国

  • 入口不是护城河：Muse 次日留存 73.3%，第 14 天掉到 22.5%，被 ChatGPT 反超；Meta 把 Wonder 放进 $20/$100 订阅，说明入口方自己也在找钱。
  • 大众消费会回到复购和推荐，撮合抽成最后滑回广告和流量逻辑，入口方之间会打成平台战。
  • 钱在两头：入口方要的真实供给和执行（搜索、沙箱、支付通道），以及商家侧的「门」（agent 身份、授权、客服防欺诈）。
  • 最可能的买家是 Twilio、Stripe、卡组织、Okta、电商和客服平台，它们要在「客服海啸」里守住自己的位置。

中国

  • 门是超级 App：腾讯 LightVela 从微信接入，字节「Spell」由豆包手机助手团队做；微信、淘宝、抖音放不放 agent，是平台说了算，不是协议说了算。
  • 所以中国没有独立的「商家侧接收层」市场，接收方就是平台自己，infra 公司只能卖给大厂或做大厂的供应商。
  • 机会在出海：国内团队直接做服务海外商家和开发者的 agent 接收、身份、执行层，用美国的买家和退出路径。

这一刻该看谁

类型 为什么是现在 参照
做过身份、风控、反欺诈的人 商家要分清好 agent、坏 agent 和被冒用的 agent Stytch、Lakera、Persona
做过支付、卡组织、商户收单的人 agent 下单要有凭证、额度和拒付规则 Stripe ACP、Visa、Mastercard
做过客服平台、懂商家后台的人 「客服海啸」最先砸到这里 Lorikeet、Pipedream
做过上一代 infra 并卖过的人 知道买家要什么，A 轮前就能被买 Pipedream、Natoma 的创始人
开源项目先有使用量的团队 买家买的是已经长在开发者那里的量 Langfuse、Browser Use、E2B
